# B2B Revenue Operations — Funnel & Forecast Dashboard

A Revenue Operations analyst's working dashboard over a **Salesforce-style B2B
pipeline**: pipeline KPIs, the Lead → Closed-Won funnel, pipeline health with a
weighted forecast against quota, and channel/segment attribution. Each view ends
with a plain-English **"So what / recommendation"** — the way a RevOps analyst
would hand findings to a sales leader.

Built by **Leo Chan — github.com/GoldenCrate**.

> ⚠️ **Synthetic data disclaimer.** Every number in this project is generated by
> `data_gen.py` with a fixed random seed. There is **no real company, customer,
> deal, or CRM/Salesforce export** anywhere in this repo. The data is shaped to
> imitate a real B2B pipeline so the analytics are realistic — but it is entirely
> fake and for demonstration only.

---

## Why this project

Mapped to a Revenue Operations Analyst brief: strong SQL/analytics instincts
applied to **B2B funnel, attribution, pipeline forecasting, and routing** on
pipeline (Salesforce-style) data. The analytics layer is written as if it were
the SQL/transform layer of a RevOps stack, then surfaced in an interactive app.

## Views

1. **KPI Overview** — open pipeline $, win rate, average deal size, median sales
   cycle (days), and quota attainment, plus booked revenue by month.
2. **Sales Funnel** — Lead → MQL → SQL → Opportunity → Closed-Won with
   stage-to-stage conversion and per-transition velocity; the weakest step is
   highlighted.
3. **Pipeline Health & Forecast** — pipeline coverage ratio (vs. the 3x–4x rule
   of thumb) and a simple **probability-weighted forecast vs. quota** waterfall.
4. **Channel / Attribution** — win rate and booked revenue by lead source,
   segment, or region.

## Design

Charts follow **Cole Nussbaumer Knaflic's _Storytelling with Data_**: muted grey
for context, a single accent color to direct attention, the key drop-off / top
channel highlighted, direct data labels instead of busy legends, and no
chartjunk.

## Project layout

| File | Purpose |
|------|---------|
| `app.py` | Multi-view Streamlit dashboard |
| `analytics.py` | Framework-free analytics (pure pandas/numpy, unit-tested) |
| `data_gen.py` | Seeded synthetic CRM opportunity/lead generator |
| `test_analytics.py` | pytest suite for the analytics layer |
| `requirements.txt` | Dependencies |

## Run locally

```bash
pip install -r requirements.txt

# regenerate / inspect the synthetic data
python data_gen.py

# run the tests
pytest -q

# launch the dashboard
streamlit run app.py
```

## Analytics layer (framework-free)

`analytics.py` has no Streamlit or plotting dependency — it is pure data logic so
it can be tested in isolation and reused:

- `kpi_summary` / `quota_attainment`
- `funnel_counts` / `funnel_conversion` / `stage_velocity`
- `weighted_forecast` / `pipeline_coverage` / `forecast_vs_quota`
- `channel_performance`

```bash
pytest -q   # covers determinism, KPI bounds, funnel monotonicity, forecast math,
            # coverage ratio, and attribution grouping
```
